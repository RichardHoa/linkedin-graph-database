# AI Chat Interface

A simple Flask + Vanilla JS chat application.

## Local Setup
1. **Activate Environment:**
   `source jupyter_env/bin/activate`
2. **Install Dependencies:**
   `pip install -r requirements.txt`
3. **Run the App:**
   `python main.py`
