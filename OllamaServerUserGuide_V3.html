Client Usage V3: Orin Inference Server

Base URL: https://apollo.quocanmeomeo.io.vn
Default Authentication: Bearer Token

Understanding the Endpoints

The API handles requests differently depending on the path you add to the Base URL:

  • /v1/chat/completions: (OpenAI Compatible) The industry standard. Best for connecting to external apps (like LangChain or OpenAI SDK). Automatically separates "Thinking" from "Answering".
  • /api/generate: (Ollama Native - Raw) Best for advanced control. You supply a single string prompt instead of a list of messages. Allows you to inject custom tags to manipulate model behavior (like turning off thinking).
  • /api/chat: (Ollama Native - Chat) Similar to OpenAI, but uses Ollama's specific JSON structure.
  • /api/pull & /api/tags: (Admin) Used to download new models or list existing ones.

DeepSeek Reasoning (Thinking Control)

Models like deepseek-r1:7b are trained to "think" before they answer. Using the /api/generate endpoint with "raw": True allows you to control this behavior perfectly.

Option 1: Enable Thinking & Print It (Raw Mode)

This script captures the raw text generation, forcing the model to output its <think> tags and reasoning process.

Thinking par start from the begining of output to the </think>. The rest will be model's answer

import socket import requests import json # Force IPv4 fix socket.getaddrinfo = lambda *args, **kwargs:[(socket.AF_INET, socket.SOCK_STREAM, 6, '', (args[0], args[1]))] # USE THE RAW GENERATE ENDPOINT url = "https://apollo.quocanmeomeo.io.vn/api/generate" headers = { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" } data = { "model": "deepseek-r1:7b", # We use the exact special tokens the model was trained on "prompt": "<|begin of sentence|><|User|>How many 'R's are in the word strawberry?<|Assistant|>", "stream": True, "raw": True # This forces Ollama to not interfere with the text } print("--- RAW GENERATION ---") try: response = requests.post(url, headers=headers, json=data, timeout=60, stream=True) for line in response.iter_lines(): if line: decoded_line = line.decode('utf-8') try: chunk = json.loads(decoded_line) # The generate API outputs straight to the "response" key if 'response' in chunk: print(chunk['response'], end='', flush=True) except json.JSONDecodeError: continue except Exception as e: print(f"\nFailed: {e}") print("\n\n--- Finished ---")

Option 2: Disable Thinking Entirely

You can force DeepSeek to skip thinking by pre-filling the Assistant's response with a closed </think> block. Change your data payload to this:

data = { "model": "deepseek-r1:7b", # We inject an empty think block to trick the model into skipping it "prompt": "<|begin of sentence|><|User|>How many 'R's are in the word strawberry?<|Assistant|><think>\n</think>\n", "stream": True, "raw": True }

Option 3: Let it Think, But DON'T Print It

The easiest way to let the model use its reasoning power but hide the output from the user is to use the OpenAI-Compatible endpoint (/v1/chat/completions). It natively hides the thinking process unless you specifically ask for it.

# USE THE V1 ENDPOINT (OpenAI Standard) url = "https://apollo.quocanmeomeo.io.vn/v1/chat/completions" data = { "model": "deepseek-r1:7b", "messages":[{"role": "user", "content": "How many 'R's are in the word strawberry?"}], "stream": True } response = requests.post(url, headers=headers, json=data, timeout=60, stream=True) print("--- OUTPUT ONLY (Thinking is hidden) ---") for line in response.iter_lines(): if line: decoded_line = line.decode('utf-8').replace('data: ', '') if decoded_line != "[DONE]": chunk = json.loads(decoded_line) # The /v1 endpoint puts final answers in 'content' # and hides thoughts in 'reasoning_content'. # We just print 'content' to hide the thinking. answer = chunk['choices'][0]['delta'].get('content', '') if answer: print(answer, end='', flush=True)

General Basic Usage

Terminal (cURL Chat)

curl -X POST https://apollo.quocanmeomeo.io.vn/v1/chat/completions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "qwen3.5:0.8b", "messages":[{"role": "user", "content": "Hello! Who are you?"}], "stream": false }'

R Language (httr2)

library(httr2) req <- request("https://apollo.quocanmeomeo.io.vn/v1/chat/completions") %>% req_headers(Authorization = "Bearer YOUR_API_KEY") %>% req_body_json(list( model = "qwen3.5:0.8b", messages = list(list(role="user", content="Hola!")), stream = FALSE )) resp <- req_perform(req) cat(resp_body_json(resp)$choices[[1]]$message$content)
