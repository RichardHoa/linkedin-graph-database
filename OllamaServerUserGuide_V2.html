Client Usage: Orin Inference Server

Public API Endpoint: https://apollo.quocanmeomeo.io.vn/v1
Default Model: qwen3.5:0.8b
Authentication: Bearer Token

This server provides an OpenAI-compatible API. You can integrate this with any standard AI tool or script by changing the base URL and providing your key.

1. Pull a New Model (Remote Admin)

Use this command to download new models directly to the Orin AGX hardware via the public endpoint.

curl -X POST https://apollo.quocanmeomeo.io.vn/api/pull \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "name": "qwen3.5:0.8b", "stream": false }'

2. Terminal (cURL Chat)

Perform a quick chat completion test from any terminal (Linux, Mac, or Windows CMD).

curl -X POST https://apollo.quocanmeomeo.io.vn/v1/chat/completions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "qwen3.5:0.8b", "messages": [{"role": "user", "content": "Hello! Who are you?"}], "stream": false }'

3. Python (Requests with IPv4 Fix)

This script includes a fix to force IPv4, preventing connection timeouts on Netbird tunnels.

import socket import requests # Force IPv4 to prevent tunnel timeout socket.getaddrinfo = lambda *args, **kwargs: [(socket.AF_INET, socket.SOCK_STREAM, 6, '', (args[0], args[1]))] url = "https://apollo.quocanmeomeo.io.vn/v1/chat/completions" headers = { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" } data = { "model": "qwen3.5:0.8b", "messages": [{"role": "user", "content": "Hello Orin!"}], "stream": False } print("Sending request via IPv4...") try: response = requests.post(url, headers=headers, json=data, timeout=30) print("Response:", response.json()['choices'][0]['message']['content']) except Exception as e: print(f"Failed: {e}")

4. R (httr2)

The modern standard for performing structured API requests in R.

library(httr2) req <- request("https://apollo.quocanmeomeo.io.vn/v1/chat/completions") %>% req_headers(Authorization = "Bearer YOUR_API_KEY") %>% req_body_json(list( model = "qwen3.5:0.8b", messages = list(list(role="user", content="Hola!")), stream = FALSE )) resp <- req_perform(req) cat(resp_body_json(resp)$choices[[1]]$message$content)

Common API Parameters

  • model: The name of the model (e.g., qwen3.5:0.8b).
  • temperature: (0.0 - 1.0) 0.0 is factual, 1.0 is creative.
  • stream: Set to false for static JSON responses.
  • num_ctx: Set the context window size (e.g. 4096).

Connection encrypted via SSL. Tunneled via Netbird. Hardware: NVIDIA Orin AGX.
